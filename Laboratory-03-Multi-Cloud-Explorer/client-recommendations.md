# Client Recommendations

### Client A – Startup Company

* **Recommended Platform:** Google Cloud Platform (GCP) / AWS
* **Recommendation Explanation:** GCP fits startups aiming for swift expansion within budget constraints thanks to cost-effective pricing structures, custom virtual machine sizing, and substantial credit programs. It enables small engineering teams to roll out scalable mobile application backends rapidly without purchasing excessive infrastructure capacity. When traffic expands, GCP handles network performance dynamically and smoothly.
* **Suggested Services:**
1. Google Cloud Run / Compute Engine
2. Cloud Firestore (Firebase backend for mobile)
3. Google Cloud Storage



---

### Client B – University

* **Recommended Platform:** Microsoft Azure
* **Recommendation Explanation:** Azure serves as the most suitable cloud environment because the institution relies heavily on Windows Server, Active Directory, and Microsoft 365 environments. Transitioning to Azure allows effortless single sign-on synchronization using Microsoft Entra ID while getting full value from current software licensing agreements. This reduces operational friction and technical onboarding demands across campus IT staff.
* **Suggested Services:**
1. Microsoft Entra ID (Azure Active Directory)
2. Azure Virtual Machines
3. Azure SQL Database



---

### Client C – AI Research Company

* **Recommended Platform:** Google Cloud Platform (GCP)
* **Recommendation Explanation:** GCP delivers top-tier throughput and built-in toolsets specifically engineered for artificial intelligence and machine learning workflows. Data scientists leverage custom TPU (Tensor Processing Unit) hardware and Vertex AI to accelerate deep learning model iterations. GCP's underlying network and compute architectures are purpose-built for heavy analytical processing workloads.
* **Suggested Services:**
1. Vertex AI
2. Google Compute Engine GPU Instances
3. BigQuery



---

### Client D – Global E-Commerce Company

* **Recommended Platform:** Amazon Web Services (AWS)
* **Recommendation Explanation:** AWS features unmatched worldwide uptime and proven server reliability built to absorb massive online shopping traffic spikes. Its international edge delivery, global database mirroring, and intelligent auto-scaling systems preserve service availability during high-volume sales. AWS’s deep service ecosystem accommodates every layer of modern, complex web architectures.
* **Suggested Services:**
1. Amazon EC2 with Auto Scaling
2. Amazon Aurora / DynamoDB
3. Amazon CloudFront (CDN)

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
| --- | --- | --- |
| **Startup Company** | GCP | Low initial cost, sustained-use discounts, and fast deployment pipelines. |
| **Enterprise Organization** | AWS | Deep market maturity, security standards, and massive infrastructure capacity. |
| **Microsoft Environment** | Microsoft Azure | Direct integration with Windows Server, Active Directory, and Azure Hybrid Benefit. |
| **AI / Machine Learning** | GCP | Industry-leading ML tools, TPUs, and specialized Vertex AI platform. |
| **Kubernetes Deployment** | GCP | Creator of Kubernetes; offers the most mature managed service (GKE). |
| **Global Web Application** | AWS | Global network of regions/edge locations, robust CDN, and proven traffic auto-scaling. |
