# Reflection

This laboratory gave me an introduction to working with a cloud-based Linux environment using KillerCoda. I learned how to create a Linux user, assign sudo privileges, access a user account, and navigate through the Linux file system.

I also gained experience in checking system information such as the operating system, kernel version, CPU, memory, and available disk space through Linux commands. Organizing directories and Markdown files also helped me understand the value of keeping a workspace properly structured.

Another key part of the laboratory was creating a GitHub portfolio. This repository will serve as a place where I can store, organize, and document my Cloud Computing laboratory activities throughout the semester.

Overall, this activity improved my knowledge of Linux administration, technical documentation, and GitHub-based version control. The skills I gained will be helpful in future cloud computing and infrastructure-related tasks.
